# 🤝 AI Collaboration Bridge (Antigravity ⟷ ChatGPT)

Thư mục này được thiết kế làm cầu nối trao đổi thông tin, chia sẻ ngữ cảnh và phân chia vai trò giữa **Antigravity** (Coding Agent trực tiếp trên máy) và **ChatGPT** (Tư vấn kiến trúc, logic hoặc brainstorm).

---

## 📌 Phân chia vai trò gợi ý

| Đặc điểm | 🤖 Antigravity (Trên máy của bạn) | 🧠 ChatGPT (Web / App) |
| :--- | :--- | :--- |
| **Thế mạnh** | Đọc/ghi file trực tiếp, quản lý Git, chạy lệnh, kiểm thử, xem cấu trúc máy | Phân tích logic phức tạp, giải thuật, prompt engineering, review ý tưởng |
| **Nhiệm vụ chính** | Thực thi code, tạo thư mục, debug runtime, commit & push | Đưa ra chiến lược, viết spec tính năng, tư vấn giải pháp |

---

## 📂 Cấu trúc các file trao đổi

* **[`chatgpt_to_antigravity.md`](./chatgpt_to_antigravity.md):**
  * Dán các chỉ dẫn, mã nguồn hoặc kế hoạch từ ChatGPT vào đây.
  * Antigravity sẽ đọc file này và tự động thực thi ngay trên dự án.

* **[`antigravity_to_chatgpt.md`](./antigravity_to_chatgpt.md):**
  * Nơi Antigravity tóm tắt trạng thái dự án, log lỗi hoặc cấu trúc thư mục để bạn chỉ cần copy 1 chạm dán sang ChatGPT.

* **[`context_sync.md`](./context_sync.md):**
  * Nhật ký tiến độ chung, các quyết định công nghệ và checklist công việc mà cả hai bên cùng theo dõi.
